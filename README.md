# word-to-pdf

Convert Word documents to PDF. Self-hosted, privacy-first, Docker-ready.

> 🚧 **Status:** Pre-alpha. Building toward `v0.1 — MVP`.
>https://github.com/users/aksharghatole/projects/3/views/1
> Track progress on the Roadmap project board.

## What this will be

Drop a `.docx` (or `.doc`, `.odt`, `.rtf`, `.txt`) into the browser, get a PDF back.
Runs entirely on your own machine — no external services, no tracking.
