# Contributing

Thanks for considering a contribution. This project is small and the bar to contribute is intentionally low.

## Ways to help

- Report bugs using the [bug template](.github/ISSUE_TEMPLATE/bug.yml)
- Propose features using the [feature template](.github/ISSUE_TEMPLATE/feature.yml)
- Pick up a [`good first issue`](https://github.com/aksharghatole/word-to-pdf/labels/good%20first%20issue)
- Improve docs, tests, or the UI
- Star the repo if you find it useful

## Getting started

Fork the repo, then clone your fork:

```bash
git clone git@github.com:YOUR_USERNAME/word-to-pdf.git
cd word-to-pdf
